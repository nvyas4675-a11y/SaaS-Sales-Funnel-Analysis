# End-to-End B2B SaaS Sales Funnel Analysis Using PostgreSQL



**Project demonstrating advanced SQL analysis on a realistic B2B SaaS sales pipeline.**

## Overview

Performed end-to-end sales funnel analysis using a synthetic dataset of a B2B SaaS company:
- 1,000 target accounts
- 12,000 leads
- 901 opportunities
- 304 won customers
- Recurring subscription revenue

## Key Achievements

- **Validated dataset** using business logic (date consistency, data duplicay,etc).
-  **60%** account-to-opportunity and **33.7%** opportunity-to-win rate.
- Identified average sales cycle of **117 days** (**98 days SMB**, **157 days Mid-Market**).
- Uncovered industry win rates: **Fintech 36%**, **Health 35%**, **SaaS 33%**, **HR 31%**.

- Analyzed marketing channels: **Inbound** = 45% lead volume, **Referrals** = highest quality (**47%** opp-to-win).
- Developed Metabse dashboard to track sales KPI like closed deal,closed amount,lost deal,lost amount,closed deal and closed amount by month,lost deal and lost value by month

## Technical Skills Demonstrated

- Advanced SQL (CTEs, aggregations, JOINs, DISTINCT for account-level metrics)
- Domain-specific data validation
- conversion calculations, segment/industry breakdowns
- Translating insights into actionable GTM recommendations
